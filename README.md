Цель
Разработать скрипты для сбора, анализа и машинного обучения на основе on-chain данных (например, Ethereum или Solana), чтобы:
выявлять крупные адреса ("китов");
кластеризовать кошельки по поведению;
обнаруживать паттерны активности (например, инсайдерские или снайперские покупки);
прогнозировать активность.
