# Hyperliquid On-Chain Analytics

Проект для непрерывного сбора и визуализации рыночных данных децентрализованной биржи Hyperliquid.

## Что делает проект

Система собирает информацию о сделках, ликвидациях, ставках финансирования и открытом интересе через публичное API Hyperliquid. Данные сохраняются в базу, после чего на их основе строится интерактивный дашборд с графиками.

Дашборд доступен онлайн и обновляется регулярно, позволяя в реальном времени оценивать активность рынка, объемы ликвидаций и настроение участников торгов.

## Основные возможности

- Сбор сделок и ликвидаций в реальном времени через WebSocket
- Периодический опрос ставок финансирования и открытого интереса
- Возможность отслеживать сделки и позиции заданных адресов
- Автоматическая генерация отчёта с графиками и публикация в интернете

Проект выполнен в рамках учебного курса.
